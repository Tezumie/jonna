# Contributing

Thanks for your interest. **We aren't accepting pull requests yet.** The codebase is still
changing quickly, and we're setting up a contributor agreement (needed because Jonna is also
offered under commercial licenses).

**What helps most right now:**
- **Bug reports.** In the app: Help → Report a problem (it collects the version and logs for
  you), or open an issue with the steps to reproduce.
- **Ideas.** Open an issue describing the problem you want solved, not only the solution.
- **Extensions.** Build them! They're yours to share or sell under your own license.

**Security issues:** don't open a public issue; see [SECURITY.md](SECURITY.md).

When contributions open, this file will explain the process and the contributor license
agreement.
