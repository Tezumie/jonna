# Security

Please report vulnerabilities privately to hello@jonna.dev. Don't open a public issue for a
security problem.

Include:
- the version (Help → About);
- your operating system;
- the steps to reproduce;
- what an attacker could do.

We aim to reply within a week, and to tell you when a fix ships. Please give us a reasonable
time to fix it before telling anyone else. There's no bug bounty yet.

**Supported versions:** the latest release. Fixes ship as a new release.
